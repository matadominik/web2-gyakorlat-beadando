E-CRAYON – INITIAL SYSTEM ADMINISTRATOR SETUP

Public registration creates student accounts only. New student registrations remain pending until a teacher approves them.

To appoint the first system administrator, use MongoDB Compass:

1. Open the existing users collection.
2. Find the trusted account that should become the system administrator.
3. Edit only that document's role field to: superadmin
4. Save the document.
5. Log out and log back in with that account.

Important:
- Do not change the role of every existing admin account.
- Existing documents with role "admin" continue to work as legacy teacher accounts.
- The superadmin manages accounts and can change passwords for student and teacher accounts. It does not manage grades as a teacher.
- From Account Administration, the superadmin can promote an approved registered student account to teacher. The account keeps its existing username and password.
- Teachers automatically receive teacher functions: manage grades, approve or reject student registrations, and view contact messages. There are no per-teacher permission settings.
- Students can access only their own gradebook and statistics.
- The superadmin is not a student and does not need a Student record.
- Do not add passwords or database credentials to source files or GitHub.

Role values:
user = student
teacher = teacher
admin = existing legacy teacher account (kept for compatibility)
superadmin = system administrator
